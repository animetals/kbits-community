# Sound bank license and provenance

Kbits currently contains four sampled kalimba banks:

| Sound | Original source | License | Provenance status |
| --- | --- | --- | --- |
| FreePats Kalimba 2019-07-23 | [FreePats](https://freepats.zenvoid.org/Ethnic/kalimba.html) | CC0 1.0 | Recorder, editors, source package, mapping, and license documented |
| Moozica Kalimba | [Musical Artifacts](https://www.musical-artifacts.com/artifacts/2931) | Public domain | Self-recording claim and public-domain statement present in both catalog and embedded SF2 metadata |
| Vini CC0 Real Kalimba | [Musical Artifacts](https://www.musical-artifacts.com/artifacts/9028) and [source repository](https://github.com/NeoSoundFonts/vini-kalimba) | CC0 1.0 | Creator and license present in embedded SF2 metadata and source repository |
| Keylimba | [Dunamis4tw/kalimba-online](https://github.com/Dunamis4tw/kalimba-online) | Immediate repository: MIT | Upstream repository and maintainer attributed; original sample creator is not separately identified by that source |

The FreePats upstream notice is preserved in `freepats-kalimba-CC0.txt`, and the immediate Keylimba distributor notice is preserved in `kalimba-online-MIT.txt`. See `THIRD_PARTY_NOTICES.md` for source hashes, provenance, mappings, modifications, and publication status.
